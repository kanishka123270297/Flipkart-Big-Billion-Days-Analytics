# Flipkart Big Billion Days – Sales Performance & Customer Insights Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze sales performance, product category trends, customer ratings, payment methods, and regional sales distribution using the available sales dataset.

## Objectives
- Analyze sales trends over time.
- Compare sales across product categories.
- Understand payment method distribution.
- Evaluate sales performance by customer rating.
- Compare quantities sold across product categories.
- Explore regional performance using an interactive slicer.

## Tools & Technologies
- Microsoft Power BI Desktop
- Power Query for data preparation
- DAX for measures and aggregations
- Data visualization and business analysis

## Dashboard Features
- **KPI Cards:** Total Sales, Max Sales, Average Rating, Quantity Sold
- **Sales Trend:** Sales Amount over time
- **Payment Analysis:** Sales distribution by payment method
- **Category Analysis:** Sales by product category
- **Rating Analysis:** Sales performance by rating
- **Quantity Analysis:** Quantity sold by product category
- **Region Slicer:** Interactive regional filtering

## Key Learnings
- Building interactive Power BI reports
- Creating and formatting KPI cards
- Selecting suitable charts for business questions
- Applying filters and slicers
- Presenting data in a business-friendly dashboard

## How to View
1. Download the Power BI `.pbix` file from this repository.
2. Open it using Power BI Desktop.
3. Use the Region slicer to explore the report.

## Note
This project is an analytical portfolio project based on the dataset used for development. It is not an official Flipkart internal sales report.
